## 核心关注点（三大痛点）

1.  **可追溯性与安全属性：** 是否关联上游需求（SysRS/SwRS/CR）及功能安全等级（ASIL）。

3.  **资源影响评估：** 是否包含量化的静态资源（Flash/RAM）及定性的动态资源（CPU Load）变化预估。

### 建议示例模版（严格遵循模版输出）

**标题**：MCAL_Gtm: 新增 PWM 通道用于 HHC 高压蓄能器排气阀控制

**描述**：

-   **溯源**：关联 SysRS-5678 / CR-2025-089 / ASIL-D 安全机制 \#SM-3.2.1
-   **受影响层级**：MCAL → Pwm Module (GTM_ConfigSet)
-   **跨层级影响**：无，仅涉及 MCAL 配置层。
-   **具体修改**：新增 PwmChannel_4，周期 100μs，分辨率 50ns，极性高电平有效，用于驱动蓄能器排气阀。
-   **资源影响**：
    -   Flash: +184 字节 (Pwm 配置表更新)
    -   RAM: +12 字节 (运行状态变量)
    -   CPU负载: +0.3%。**评估依据：** 基于新增中断服务函数（ISR）100μs 调用一次的频率，以及预估的 300 条指令执行量，通过 Worst-Case Execution Time (WCET) 分析得出。
-   **标定与工具链**：
    -   **工具链：** EB tresos V2.3.1，配置文件生成路径：`/Cfg/Gen/Pwm.c`
    -   `Cal_HHC_ExhaustDutyInit`: 默认 35%, 范围 0–100%, 分辨率 0.1%, **物理意义：** HHC 高压蓄能器排气阀的初始占空比。
-   **安全相关**：是，涉及电磁阀驱动诊断，关联 DTC B2003-11。
-   **风险与回滚**：**潜在风险**为配置错误导致 PWM 输出异常；**回滚方案**是直接回退至上一个通过验证的 Pwm Module 配置版本。

---
### 典型 FAIL 痛点（应打回重写）

-    **模块模糊**：未写任何 AUTOSAR 层级，仅写“增加一个驱动”。
-    **参数缺失**：增加 PWM 但不写通道号、周期、极性等关键硬件约束。
-    **敷衍评估**：资源影响写“微小”、“忽略不计”或“无影响”而无**定性理由**。
-    **标定不全**：新增标定参数缺失默认值、范围或物理单位。
-    **工具链缺失**：未说明配置工具的版本或路径。
-    **安全缺失**：底盘核心执行器修改却未提及 ASIL 等级或安全机制。
