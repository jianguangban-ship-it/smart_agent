## 核心关注点（三大痛点）

1.  **可追溯性与量化指标：** 是否关联上游需求（SysRS/客户规格/封装标准/CR）；热、振动、密封等指标是否量化（W、℃、g²/Hz、IP 等级），**严禁**"影响不大"、"应该没问题"等主观判断。
2.  **几何与接口清晰度：** 修改是否给出具体的零件号/图号、包络尺寸变化、关键尺寸及 GD&T 公差、安装与连接器接口约束，**严禁**无尺寸的模糊描述。
3.  **制造与验证影响评估：** 是否评估对模具/工艺（拔模角、壁厚、充型）的影响，并定义验证手段（CFD/FEA 仿真、DV 试验）与可度量的验收标准。

## 检查清单（JIRA Description Review Checklist）
---
### 1. 共有项（所有任务必查）

| 检查项 | 优化后要求 |
| :---: | :---: |
| **溯源关联** | **必须**关联需求 ID / SysRS / 客户规格 / 封装标准 / CR / Bug ID 等上游 ID。 |
| **零件标识** | **必须**指明受影响的零件号/图号及版本（如 `IBC2-SHELL-LOWER-001 Rev.B`）。 |
| **标题规范** | 需包含 `零件/模块名: 动作描述`（如：`下壳体: 新增散热筋用于功率区散热增强`）。**标题应精炼、准确地概括修改的核心内容**，并确保与任务描述的**第一要点**高度一致。 |

### 2. 结构与接口必要项

| 检查项 | 优化后要求 |
| :---: | :---: |
| **包络与禁区** | **必须**给出外包络（长×宽×高）变化量、安装方向，并确认与周边件的禁区/间隙。 |
| **关键尺寸与公差** | **必须**提供关键尺寸及 GD&T 公差（如筋高、安装面平面度），**严禁**只写“加几个筋”、“改一下壳体”而无几何参数。 |
| **安装与连接器接口** | 涉及安装/接口变更时，**必须**定义支架类型、紧固件规格（螺栓尺寸、扭矩）、连接器类型/插拔方向/锁止机构。 |
| **跨专业影响** | **若修改影响 PCB 布局、线束走向或整车布置**，**需明确列出所有受影响的**专业/零件**清单。** |

### 3. 热管理与环境耐久项

| 检查项 | 优化后要求 |
| :---: | :---: |
| **热源与量化目标** | 涉及散热的修改**必须**识别主要热源及功耗（W），并给出量化目标（如结温 ≤X℃ 或热阻下降 Y%）。**需简述评估依据**（例如：CFD 仿真、实测数据、经验公式），**严禁**使用“影响不大”、“应该没问题”等模糊词语。 |
| **散热路径** | **必须**描述 TIM 型号/厚度、散热器/散热筋几何或气流路径。 |
| **IP 与密封** | **必须**说明本次修改是否影响密封面、目标 IP 等级（IP67/IP6K9K）及密封策略。 |
| **振动/冲击/防腐** | **必须**引用振动剖面（ISO 16750-3）及表面处理/盐雾要求（小时数），或明确声明不受影响并给出理由。 |

### 4. 材料、制造与验证项

| 检查项 | 优化后要求 |
| :---: | :---: |
| **材料选型** | **必须**指明材料牌号（如 PA66-GF30, ADC12）及选型理由（导热、强度、成本）。 |
| **DFM/DFA 与模具影响** | **必须**评估拔模角、壁厚、充型、装配顺序的影响；涉及模具变更时说明模具改造范围与供应商确认状态。 |
| **工具与数据** | **必须说明** CAD 工具及**版本号**（如 CATIA V5 R2021）、3D/2D 数据的 PDM 编号或存放路径，以确保设计数据可追溯。 |
| **验证与验收** | **必须**定义验证手段（CFD/FEA 仿真报告、DV 试验项）及可度量的验收标准，**严禁**以“尽快完成”代替验收标准。 |

### 建议示例模版（严格遵循模版输出）

**标题**：下壳体: 新增散热筋用于 IBC 功率 MOSFET 区域散热增强

**描述**：

-   **溯源**：关联 SysRS-3021 / 客户热管理规范 §4.2 / CR-2026-045
-   **受影响零件**：IBC2-SHELL-LOWER-001 Rev.B（压铸下壳体）
-   **跨专业影响**：无 PCB 布局变更；外包络高度 +4mm，已与整车布置确认禁区间隙 ≥15mm。
-   **具体修改**：功率区新增 6 条散热筋，筋高 12mm（公差 +0/-0.3mm），筋厚 2.5mm，节距 8mm，拔模角 ≥1.5°；外包络由 220×185×62mm 变更为 220×185×66mm。
-   **热管理**：
    -   热源：Q1–Q6 功率 MOSFET，持续功耗 18W（峰值 28W）
    -   量化目标：结温由 148℃ 降至 ≤142℃（限值 150℃）。**评估依据：** CFD 仿真（报告 IBC2-SIM-2026-031），样件实测与仿真偏差要求 ≤10%。
    -   TIM：Bergquist GP3000，厚度 0.5mm
-   **材料与制造**：ADC12（导热系数 96 W/m·K，沿用现有模具材料体系）；模具改造范围已与供应商确认，壁厚/充型无风险。
-   **工具与数据**：CATIA V5 R2021，3D 数据 PDM 编号 `PDM-IBC2-ME-0457`。
-   **环境耐久**：不涉及密封面，IP67 策略不变；散热筋经 ISO 16750-3 Z 轴振动 FEA 确认无共振风险；表面阳极氧化，盐雾 ≥500h。
-   **验收标准**：更新版热仿真报告达标；DFM 评审通过；2D 图纸 GD&T 标注完整并签署。
-   **风险与回退**：**潜在风险**为模具改造后充型不良；**回退方案**为恢复上一版模具镶块（原镶块保留至 DV 试验通过）。

### 典型 FAIL 痛点（应打回重写）

-    **几何模糊**：只写“加几个散热筋”、“改一下壳体”，无尺寸、公差、零件号。
-    **敷衍评估**：热/振动影响写“影响不大”、“应该没问题”而无量化数据与**评估依据**。
-    **材料缺失**：未指明材料牌号或选型理由。
-    **制造缺位**：未评估拔模角、壁厚、模具改造影响。
-    **验证缺失**：无仿真/试验验证计划，验收标准不可度量（如“尽快完成”）。
-    **溯源缺失**：未关联上游需求、客户规格或变更单（CR）。
